# 06-UI

UI adalah implementasi dari:
Requirement → Workflow → Permission → Data

Bukan sumber requirement.

Agent tidak boleh menambahkan:
- button,
- page,
- modal,
- filter,
- chart,
- animation,
- tooltip,
- notification,
- interaction,
tanpa requirement atau explicit user instruction.

## UI CONSISTENCY
Gunakan design system existing.
Jangan mengganti:
- color,
- typography,
- spacing,
- component style,
- layout pattern,
hanya karena agent merasa lebih bagus.
Jika user meminta redesign, baru lakukan.

## UI Terminology
Terminology UI harus mengikuti glossary dan final requirements. Terminology obsolete (contoh: PIC, Admin) tidak boleh digunakan pada UI baru. Terminology final project harus konsisten (Super Admin, Koordinator, Verifikator).
