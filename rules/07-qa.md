# 07-QA

QA tidak boleh mengubah expected behavior berdasarkan asumsi.

Test harus berasal dari:
- Requirement
- Business Rule
- Acceptance Criteria
- Approved behavior

Jika behavior belum ditentukan:
**UNDEFINED BEHAVIOR**
Jangan membuat expected result sendiri.

Test harus dapat membedakan:
- bug,
- requirement gap,
- documentation gap,
- implementation gap.
