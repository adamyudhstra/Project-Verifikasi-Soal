# 05-API

API documentation harus membedakan:
- IMPLEMENTED
- PLANNED
- DEPRECATED
- MISSING

Jangan menyebut endpoint implemented jika hanya ada di docs.

Agent tidak boleh mendokumentasikan endpoint sebagai implemented jika endpoint tersebut tidak ada.
Agent tidak boleh membuat endpoint baru tanpa requirement.

API contract harus konsisten dengan:
- Requirement
- Permission
- Database
- Workflow
- Frontend usage
