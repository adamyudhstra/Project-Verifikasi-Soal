# 08-SECURITY

Security behavior harus berdasarkan:
- approved permission,
- role,
- ownership,
- assignment,
- authentication requirement.

Jangan memperluas permission secara otomatis.
Jangan mengurangi permission secara otomatis.

Jika permission tidak jelas:
**OPEN DECISION.**

Sensitive information tidak boleh dimasukkan ke documentation tanpa kebutuhan.
